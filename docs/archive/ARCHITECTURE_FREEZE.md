## 1. التفرقة المعمارية الحاسمة: الوجهة (Destination) ↔ صفحة تفاصيل الوجهة (Destination Details Page)

> [!IMPORTANT]
> **الوجهة الأساسية** و **صفحة تفاصيل الوجهة** هما عنصران منفصلان تماماً معمارياً:

### أ) بيانات الوجهة الأساسية (Destination Core Data) — مسؤولية التطبيق حصراً
- **المسؤولية**: تُدار وتُجلب حصراً من التطبيق عبر الـ API (`/v1/destinations` أو Firestore `destinations`).
- **المحتوى التشغيلي**:
  - اسم المدينة/الوجهة (عربي/إنجليزي)
  - الصورة الرئيسية للوجهة التشغيلية
  - الدولة والمحافظة
  - عدد الفنادق المتاحة بالمدينة
  - الإحداثيات الجغرافية (Lat/Lng)
  - أي بيانات تشغيلية برمجية
- **حظر تعديل لوحة الموقع**: **يُمنع منعاً باتاً تعديل أو إنشاء هذه البيانات من لوحة تحكم الموقع (Website CMS).**

### ب) صفحة تفاصيل الوجهة (Destination Details Page) — مسؤولية Website CMS حصراً
- **المسؤولية**: صفحة تسويقية مستقلة خاصة بالموقع تُدار بالكامل عبر لوحة تحكم الموقع (`/admin/destinations`).
- **المحتوى التسويقي والتحريري**:
  - ترويسة الصفحة التسويقية (Hero Section & Banner)
  - إعدادات الـ SEO والـ Meta Tags (Title, Description, OG Image, Canonical URL)
  - الوصف التاريخي والثقافي المطوّل للوجهة
  - دليل السفر والنصائح (أفضل وقت للزيارة، الطقس، النقل)
  - قائمة المعالم السياحية والتاريخية والأنشطة (Landmarks & Attractions)
  - معرض الصور التحريرية ومقاطع الفيديو (Editorial Photo Gallery & Video)
  - الأسئلة الشائعة الخاصة بالمدينة (City FAQ)
  - دعوة الاتخاذ إجراء (CTA)
- **استقلالية المحتوى**: هذا المحتوى لا يتبع لبيانات التطبيق التشغيلية وتستقبله واجهة الموقع للزوار فقط.

## 2. مسؤولية التطبيق (Mobile App — Flutter)

التطبيق هو المسؤول **الوحيد** عن إدارة وتعديل البيانات التشغيلية التالية:

- الفنادق، الغرف، الأسعار، والمواسم
- المرافق والخدمات الفندقية
- الحجوزات وإدارة حالاتها وتأكيدها
- المستخدمين والمصادقة (Firebase Auth)
- الحسابات البنكية للمزودين
- الإدارة المالية والعملات وسعر الصرف
- العروض والخصومات والبنرات الترويجية للتطبيق
- الإعلانات والإشعارات لحظياً
- بيانات الوجهات الأساسية (قائمة المدن التشغيلية)

**لا يُسمح لأي نظام آخر بتعديل هذه البيانات التشغيلية.**

## 3. مسؤولية API

- الوسيط **الوحيد** بين التطبيق والموقع
- ينقل البيانات التشغيلية فقط — لا يحتوي أي Business Logic خاص بالموقع
- لا يُسمح للموقع بامتلاك نسخة مستقلة من بيانات التطبيق
- Endpoint الرسمي: `https://us-central1-msariapp-v2.cloudfunctions.net/api/v1`

## 4. مسؤولية الموقع (Website — Next.js)

الموقع مسؤول **فقط** عن تقديم وإدارة الواجهات التسويقية التالية:

### الواجهات والمحتوى التسويقي
| الصفحة / الموديول | الوصف | مصدر البيانات |
|------------------|-------|-------------|
| **الصفحة الرئيسية** | Hero, أقسام المميزات, بانرات, نصوص الشركاء | Firestore CMS / محلي |
| **صفحة تفاصيل الوجهة** | المحتوى التسويقي، المعالم، FAQ المدينة، الـ SEO | Firestore `web_destinations` / CMS |
| **المدونة والمقالات** | مقالات السفر والأدلة السياحية | Firestore `blog_posts` |
| **عن مساري** | صفحة من نحن التعريفية | محتوى ثابت / CMS |
| **اتصل بنا** | نموذج التواصل والدعم | محتوى ثابت / CMS |
| **صفحة التطبيق** | صفحة الترويج لتحميل التطبيق | Firestore CMS / محلي |
| **أضف فندقك** | **طلب انضمام شريك فقط — وليس إنشاء فندق** | نموذج استقبال طلبات |

### صفحات عرض الخدمات
| الصفحة | الوصف | مصدر البيانات |
|--------|-------|-------------|
| **خدمة السيارات** | عرض خدمات وأسطول السيارات والتأجير | Firestore `web_cars` / CMS |
| **تاكسي المطار** | خدمة التوصيل والاستقبال للمطار | Firestore `web_cars` / CMS |
| **النقل بين المدن** | الرحلات والتنقل بين المدن | Firestore `web_cars` / CMS |
| **رحلات الطيران** | بحث وعرض رحلات الطيران | External Flight API Proxy |
| **الفنادق العالمية** | عرض الفنادق العالمية | External Global Hotel API Proxy |
| **الفنادق المحلية** | عرض واستكشاف الفنادق المحلية (**قراءة فقط**) | API التطبيق (`/v1/hotels`) |

### البنية التحتية والمحتوى العام
| العنصر | الوصف |
|--------|-------|
| **الهيدر والفوتر** | روابط الملاحة والقوائم |
| **إعدادات SEO** | Meta tags, OpenGraph, Structured Data, Sitemap, Robots |
| **الصفحات الثابتة** | الخصوصية، الشروط والأحكام |
| **صفحة المطورين** | وثائق API وتلقي طلبات المفاتيح |

## 5. مسؤولية لوحة تحكم الموقع (Website Admin Panel)

تدير لوحة التحكم (`/admin`) **فقط** المحتوى التسويقي غير الموجود داخل التطبيق:

| القسم | المسار | وظيفة القسم التشغيلية في CMS |
|-------|--------|-----------------------------|
| **Dashboard** | `/admin` | ملخص وإدارة واجهة CMS المستقلة |
| **Destinations** | `/admin/destinations` | إدارة المحتوى التسويقي، المعالم، الصور، والـ SEO لصفحات تفاصيل الوجهات |
| **Cars** | `/admin/cars` | إدارة نصوص وأسعار ومحتوى صفحات أسطول السيارات والتوصيل |
| **App Landing** | `/admin/app-landing` | إدارة نصوص، صور، وروابط صفحة تحميل التطبيق |
| **Settings** | `/admin/settings` | إدارة بيانات التواصل، المرافق العامة للموقع، والإعدادات التسويقية |

### ⛔ المحظورات القاطعة في لوحة تحكم الموقع
- ❌ حظر إنشاء أو تعديل الفنادق والغرف والأسعار
- ❌ حظر عرض أو تعديل الحجوزات التشغيلية
- ❌ حظر إدارة المستخدمين والمشرفين والصلاحيات
- ❌ حظر إدارة العروض التشغيلية للتطبيق
- ❌ حظر الإدارة المالية والحسابات البنكية والعملات
- ❌ حظر مفاتيح API للمطورين والإشعارات الفورية
