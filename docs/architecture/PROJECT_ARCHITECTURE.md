# 🏛️ المشروع والمعمارية العامة لمنصة مساري (Project Architecture Specification)

**النظام**: منصة مساري الرقمية (`msari_web`)  
**الدور الرسمي**: Chief Software Architect, Enterprise Documentation Lead, Technical Governance Officer  
**الحالة المعمارية**: 📜 **مرجع معماري معتمد ورسمي (Official Architecture Blueprint - Single Source of Truth)**

---

## 📑 1. الملخص التنفيذي (Executive Summary)

تحدد هذه الوثيقة المعمارية العامة الشاملة لمنصة مساري الرقمية (`msari_web`). بُنيت هذه المعمارية لضمان الاستقرار المؤسسي والأداء العالي والاستقلالية التامة بين كافّة مكونات النظام.

المرجع المعماري الرسمي والوحيد المعتمد للمشروع هو وثيقة **`Final Data Architecture Specification`**؛ حيث يلتزم كافّة المطورين ووكلاء الذكاء الاصطناعي (AI Agents) بهذه المقررات المعمارية دون أي اجتهاد أو تغيير.

---

## 🛡️ 2. المبادئ المعمارية الحاكمة (Architecture Principles)

1. **مصدر واحد للحقيقة (Single Source of Truth)**:
   تعتبر هذه الوثائق المعمارية في مجلد `/docs/architecture/` المرجع الرسمي والوحيد المعتمد للمشروع لكل مطور أو وكيل AI مستقبلاً.
2. **الفصل التام بين محتوى التطبيق ومحتوى الموقع (Strict 3-Layer Decoupling)**:
   فصل بيانات تطبيق الجوال المشتركة عن محتوى وإدارة الموقع الخاص لضمان التطور المستقل لكل طبقة.
3. **نموذج الخوادم الموزعة بدون SQL (Zero-SQL Serverless Model)**:
   الاعتماد الكلي على **Firebase Firestore** كـ Document Database موحدة وإهمال أي قواعد بيانات SQL خاضعة لـ Prisma/Supabase.
4. **الأمان أولوية أولى (Security Guard First)**:
   تنفيذ التحقق من الصلاحيات كأول خطوة حتمية في كافّة الـ Server Actions الموجهة للإدارة عبر `adminGuard`.
5. **طبقة الصمود والتراجع (Resilience Fallback Layer)**:
   توفير بيانات ثنائية احتياطية تضمن عمل الواجهات والملاحة بدون توقف عند انقطاع أي خدمة خادم.

## 🎛️ 4. معمارية لوحات التحكم (Admin Panels Architecture)

تتكون المنظومة من فصل معماري واصل بين لوحتين مع بقاء قاعدة البيانات موحدة على **Firebase Firestore**:

1. **لوحة إدارة التطبيق (Application Admin)**:
   - المسار: `/admin/*`
   - المسؤولية: إدارة البيانات المشتركة مع التطبيق (الفنادق، الغرف، الحجوزات، المستخدمين، العروض، وحسابات البنوك).
2. **لوحة إدارة محتوى الموقع (Website Admin / CMS)**:
   - المسار: `/admin/website/*`
   - المسؤولية: إدارة المحتوى التسويقي، أسطول السيارات، معالم وتفاصيل الوجهات، الصفحات الثابتة، والـ SEO المباشر لكل صفحة.

## ❓ 5. الأسئلة المعمارية المفتوحة (Open Architectural Questions)

> [!NOTE]
> هذا القسم مخصص لتوثيق أي نقاط أو تساؤلات معمارية قابلة للتوضيح واتخاذ القرار بشأنها حصراً من قِبل صاحب المشروع:

1. **نطاق التحكم بأسطول السيارات**: هل ترغب في ربط حجوزات السيارات بنظام إشعارات WhatsApp المباشر أم إبقائها ضمن جدول الحجوزات الخاص بـ `web_car_bookings`؟
2. **مزود الصور والأصول (Media Library Provider)**: هل يُعتمد Firebase Storage كحاوية حصرية لصور الـ Website CMS أم ربطه بـ Cloudinary للتثقيل والتمرير السريع؟
