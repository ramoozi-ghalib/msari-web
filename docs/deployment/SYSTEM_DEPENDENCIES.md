# 🔗 خريطة وحوكمة اعتماديات النظام (System Dependencies & Topology)

**الصفة الرسمية**: Chief Software Architect, DevOps Architect, Release Manager, Technical Governance Officer  
**المشروع**: منصة مساري الرقمية (`msari_web`)  
**الحالة**: 📜 **مستند رسمي معتمد لبنية واعتماديات المنظومة (System Dependencies Map)**

---

## 📑 1. الخدمات والمنصات الخارجية (External Services)

1. **منظومة Firebase السحابية**:
   - **Firestore Database**: خزان المستندات الموحد للبيانات التشغيلية ومحتوى الـ Website CMS.
   - **Firebase Authentication**: إدارة هويات ومصادقة حراس اللوحة والمستخدمين.
   - **Firebase Storage**: استضافة وحفظ أصول وصور الفنادق والمستندات.
   - **Firebase Cloud Functions**: واجهات الـ API المباشرة للتطبيق والموقع.
2. **مزودو واجهات الطيران (External Flight APIs)**:
   - واجهات البرمجة المباشرة لمحرك بحث ورحلات الطيران.
3. **مزودو واجهات الفنادق العالمية (International Hotel APIs)**:
   - المزودون الخارجيون لإمداد الفنادق الدولية بالأسعار والتوافر الحرج.

---

## 🏢 2. الخدمات والأنظمة الداخلية (Internal Services)

1. **نظام إدارة محتوى الموقع (Website CMS Services)**:
   - الموديولات المستقلة لإدارة الصفحة الرئيسية، أسطول السيارات، معالم المدن، FAQ، و SEO.
2. **نظام إدارة التطبيق (Application Admin Services)**:
   - الموديولات المشتركة مع التطبيق لإدارة الفنادق المحلية، الغرف، الحجوزات، والمالية.
3. **الخدمات المشتركة (Shared Core Services)**:
   - خدمات الترجمة والتوجيه (i18n), إدارة العملات (Currency), ومصادقة جلسات الـ JWT.

---

## 🛠️ 3. اعتماديات البناء (Build Dependencies)

- **Node.js**: البيئة التشغيلية المعتمدة (الإصدار `20.x` أو `22.x` LTS).
- **npm**: مدير الحزم التشغيلي للمشروع.
- **Next.js**: إطار العمل الرئيسي (الإصدار `16.2.1` مع دعم Turbopack و App Router).
- **TypeScript**: لغة التطوير الأساسية (الإصدار `5.x`).
- **Prisma ORM**: 
  - **الحالة الحالية**: **مكتبة متبقية غير مستخدمة برمجياً في الإنتاج (Legacy / Unused Dependency)**.
  - **التوضيح**: تم نقل جميع الاستعلامات والعمليات بنجاح إلى Firebase Firestore، ولا تتطلب بيئة الإنتاج أي اتصال بقواعد بيانات SQL المربوطة بـ Prisma.

---

## ⚙️ 4. اعتماديات وقت التشغيل (Runtime Dependencies)

- **متغيرات البيئة والأنظمة (Environment Variables & Secrets)**: مفاتيح المصادقة وروابط الخدمة.
- **المصادقة والأمان (Authentication & Security)**: `@auth/prisma-adapter` / `next-auth` (JWT Strategy).
- **معالجة الصور والشبكة (Images & CDN)**: دعم النطاقات المصرحة لـ Unsplash, Firebase Storage, و Supabase Storage بـ `next.config.ts`.
- **المكتبات الثانوية الحركية والتصميم**:
  - `framer-motion`: للتحريكات الدقيقة.
  - `lucide-react`: مكتبة الأيقونات القياسية.
  - `tailwind-merge` & `clsx`: لإدارة وتجميع تنسيقات CSS.
  - `swiper`: للسلايدرات والعروض.

## 🚨 6. سيناريوهات الأعطال وتحليل الأثر (Failure Scenarios & Impact Analysis)

توضح هذه القائمة الأثر التشغيلي عند تعطل أي خدمة وطريقة معالجتها تلقائياً:

| الخدمة المتعطلة | الأثر التشغيلي (Impact Scope) | طبقة التخفيف والصمود (Mitigation Layer) |
| :--- | :--- | :--- |
| **Firebase Firestore** | تعذر جلب الفنادق المحلية وتغيير الحجوزات | **مُخفف**: يتم استخدام البيانات الثنائية بـ `destinations.ts` والذاكرة المؤقتة لعرض الصفحات دون انهيار السيرفر. |
| **Flight API** | تعثر البحث المباشر في رحلات الطيران | **مُخفف**: إظهار رسالة توضيحية للعميل مع تحويل الطلب للدعم والمتابعة عبر الواتساب المباشر. |
| **International Hotel API**| تعثر جلب أسعار الفنادق العالمية | **مُخفف**: توجيه الزائر واستعراض الفنادق المحلية بـ Firestore مع رسالة تنبيهية. |
| **Firebase Storage** | عدم ظهور بعض صور الفنادق الجديدة | **مُخفف**: استخدام الصور الاحتياطية الثابتة (Placeholder Fallback Images). |
| **Firebase Auth** | تعذر تسجيل دخول عملاء جدد | **مُخفف**: استمرار تصفح الموقع والخدمات وإتاحة الحجز المباشر كزائر (Guest Booking). |
