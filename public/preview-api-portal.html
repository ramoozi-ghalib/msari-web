FAQ

الأسئلة الشائعة

إجابات سريعة وواضحة حول الربط البرمجي وطرق العمل.

1 كيف أحصل على مفتاح API الخاص بي؟

تواصل معنا عبر واتساب الشركاء وسيتم تزويدك بمفتاح الربط البرمجي بعد مراجعة طلب الشراكة وتوثيق الحساب.

2 هل يدعم الـ API تأكيد الحجز الفوري وإصدار القسيمة؟

نعم، يتيح الـ API إتمام وتأكيد الحجز الفوري مع خصم التوفر لحظياً وإصدار رقم مرجعي معتمد ومباشر لدى إدارة الفندق وقسيمة حجز إلكترونية.

3 ما هي صيغة البيانات المعتمدة في الـ API؟

البيانات تُرسل وتُستقبل بصيغة JSON القياسية عبر بروتوكول HTTPS المشفر، مع توفير Webhooks للإشعارات والتحديثات المباشرة لحالة الحجز.

4 هل يتوفر دعم فني وهندسي أثناء عملية التكامل؟

نعم، نوفر دعماً فنياً وهندسياً مباشراً لمساعدتك في إتمام عملية الربط والتكامل خطوة بخطوة عبر واتساب.

جاهز لبناء شراكة سفر متكاملة مع مساري؟

فريقنا التقني وإدارة الشراكات مستعدون لتقديم الدعم الفني وتسهيل عملية الربط خطوة بخطوة.
